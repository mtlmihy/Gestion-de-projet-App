1. Vue d'ensemble & architecture

Application web fullstack, multi-projet, multi-utilisateur

L'application est une plateforme de gestion de projets professionnelle destinée aux chefs de projet, aux équipes internes et aux clients. Elle centralise toutes les informations d'un projet dans une interface unifiée, accessible en ligne depuis n'importe quel navigateur.

🏗️ Architecture

  • Frontend React 19 + Vite + Tailwind CSS
  • Backend FastAPI (Python) + asyncpg
  • Base de données PostgreSQL (Supabase)
  • Déploiement : Vercel (front) + Render (back)

🎨 Interface

  • Mode clair / mode sombre (toggle)
  • Design responsive (mobile + desktop)
  • Drawer mobile pour la navigation
  • Notifications toast en temps réel

🔄 Multi-projet

  • Sélecteur de projet au démarrage
  • Changement de projet rapide depuis la navbar
  • Contexte projet conservé en localStorage

📱 Accessibilité

  • Navigation clavier complète
  • Modals avec gestion du scroll body
  • Labels ARIA sur les boutons d'action
🔐

2. Authentification & sécurité

JWT HttpOnly, CSRF, rate limiting, audit log

🔑 Connexion sécurisée

  • JWT stocké en cookie HttpOnly (non accessible JS)
  • Token CSRF double-submit (protection CSRF)
  • Rate limiting sur les endpoints sensibles
  • Tarpit : délai progressif après échecs de connexion

🔒 Politique de mot de passe

  • Minimum 12 caractères
  • Au moins 1 majuscule, 1 minuscule
  • Au moins 1 chiffre et 1 caractère spécial
  • Hachage bcrypt côté serveur

📝 Journal d'audit

  • Traçabilité de toutes les actions sensibles
  • Enregistrement : IP, user-agent, action, timestamp
  • Table audit_log en base de données

🔄 Gestion de session

  • Changement de mot de passe depuis le profil
  • Révocation de session à la déconnexion
  • Forçage de déconnexion par un admin
  • Session invalidée automatiquement après changement de MDP
📁

3. Gestion des projets

Création, configuration, clôture et suppression de projets

➕ Création de projet

  • Nom, description, statut initial
  • Type : Interne ou Client
  • Le créateur devient automatiquement Propriétaire
  • Accessible aux admins et chefs de projet

⚙️ Paramètres projet

  • Modification du nom, description, statut
  • Changement de type (Interne ↔ Client)
  • Budget prévu et devise (CHF / EUR) pour projets Client
  • Clôture et réactivation du projet

👁️ Pages visibles

  • Le propriétaire choisit les pages actives pour le projet
  • Masquage de modules non utilisés (Planning, COPIL…)
  • Page Budget réservée aux projets de type Client

🔗 Liens externes

  • Ajout de liens web associés au projet
  • Titre + URL, ouverture dans un nouvel onglet
  • Gestion (ajout / suppression) par les éditeurs
Un projet clôturé passe en lecture seule pour tous les membres non-admin. Seul un administrateur peut réactiver un projet clôturé.
🛡️

4. Rôles & permissions

Contrôle d'accès granulaire par projet et par page
Rôle Qui ? Droits Restrictions
Administrateur Équipe IT / DG Accès total à tous les projets et à la page Admin Aucune
Propriétaire Chef de projet CRUD complet, gestion membres, paramètres, pages, ordre menu Limité à ses projets
Éditeur Consultant, collaborateur Créer, modifier, supprimer les données du projet Pas de gestion des membres ni paramètres
Lecteur Manager, observateur Consultation uniquement, aucune modification Toutes les pages en lecture seule
Client Client final Accès à un sous-ensemble de pages défini par le propriétaire Pages restreintes, lecture seule
Gestion des accès membre : Le propriétaire peut définir quelles pages sont visibles pour chaque membre de type Client, offrant un contrôle très fin de l'information partagée.

5. Registre des risques

Identification, évaluation et suivi des risques projet

📋 Fiche de risque

  • Titre et description du risque
  • Probabilité (1 à 5) et Impact (1 à 5)
  • Score de criticité calculé automatiquement (P × I)
  • Statut : Ouvert, En cours, Résolu, Accepté

📊 Catégorisation

  • Catégories : Technique, Planning, Budget, Humain, Juridique, Autre
  • Niveau de criticité : Faible / Moyen / Élevé / Critique
  • Tri et filtrage par catégorie et niveau

🛡️ Plan de mitigation

  • Description de la stratégie de réponse
  • Assignation d'un responsable (membre de l'équipe)
  • Date d'échéance pour la résolution

📈 Tableau de bord

  • KPIs : total, ouverts, critiques, résolus
  • Filtres par statut et par catégorie
  • Indicateurs visuels colorés par niveau de risque
✅

6. Suivi des tâches

Gestion complète des tâches avec statuts, priorités et assignation

📝 Fiche tâche

  • Titre, description, date de début et d'échéance
  • Statut : À faire, En cours, En révision, Terminé, Annulé
  • Priorité : Basse, Normale, Haute, Urgente
  • Assignation à un membre de l'équipe

🏷️ Organisation

  • Filtrage par statut, priorité, assigné
  • Tri par date d'échéance ou priorité
  • Indicateurs visuels de retard (tâches en rouge)
  • Compteur de tâches par statut

📊 KPIs tâches

  • Total des tâches, terminées, en cours
  • Tâches en retard (date dépassée)
  • Barre de progression globale du projet

🔒 Contrôle d'accès

  • Création/modification réservée aux Éditeurs+
  • Accès en lecture pour Lecteurs et Clients
  • Vérification de l'appartenance au projet côté API
📅

10. Matrice RACI

Responsabilités par tâche et par membre

📊 Matrice interactive

  • Lignes = tâches / activités du projet
  • Colonnes = membres de l'équipe
  • Cellules : R (Responsable), A (Approbateur), C (Consulté), I (Informé)

✏️ Édition

  • Clic sur une cellule pour assigner un rôle RACI
  • Ajout / suppression de lignes d'activités
  • Sauvegarde immédiate de chaque changement
Lettre Rôle RACI Signification
RResponsibleExécute la tâche
AAccountableRend compte du résultat, approbateur final
CConsultedConsulté avant/pendant l'exécution
IInformedInformé après l'exécution

12. Suivi budgétaire

Réservé aux projets de type Client — Suivi des dépenses engagées
Cette fonctionnalité est disponible uniquement pour les projets de type Client. Elle n'apparaît pas dans le menu pour les projets Internes.

📊 Tableau de bord budget

  • Budget prévu vs dépenses engagées
  • Solde restant (vert si positif, rouge si dépassé)
  • Barre de progression avec seuils visuels (80% = orange, 100% = rouge)
  • Nombre total de lignes de dépenses

💰 Lignes de dépenses

  • Date, catégorie, description, montant
  • Catégories : Prestation, Matériel, Déplacement, Formation, Sous-traitance, Autre
  • Devise projet (CHF ou EUR)
  • Ajout, modification, suppression

🔍 Filtrage

  • Filtre par catégorie de dépense
  • Total recalculé en temps réel selon le filtre actif
  • Tableau avec total récapitulatif en pied

🔒 Droits d'accès

  • Lecture : tous les membres du projet
  • Ajout / modification / suppression : Éditeur et Propriétaire uniquement
  • Mode lecture seule automatique pour Lecteurs et Clients
⚙️

13. Administration

Réservée aux administrateurs — Gestion globale des utilisateurs et accès

👤 Gestion des utilisateurs

  • Créer, modifier, désactiver, supprimer un compte
  • Attribuer le rôle Admin ou Chef de projet
  • Réinitialiser le mot de passe d'un utilisateur
  • Voir le statut actif/inactif de chaque compte

🗺️ Matrice des permissions

  • Vue croisée utilisateurs × projets
  • Modification du rôle directement dans la cellule
  • Ajout/retrait d'un utilisateur d'un projet
  • Date de dernière connexion visible

📊 KPIs de gouvernance

  • Nombre d'utilisateurs actifs / admins / chefs de projet
  • Projets sans propriétaire détectés
  • Comptes dormants (inactifs > 90 jours)
  • Liste des anomalies de gouvernance

🚨 Actions de sécurité

  • Forcer la déconnexion : révoque toutes les sessions actives d'un utilisateur
  • Offboarding : retire de tous les projets + désactive le compte + révoque les sessions
  • Compte non supprimé, réactivable si besoin
🗂️

14. Navigation personnalisable

Propriétaires peuvent réorganiser les onglets du menu

🖱️ Glissé-déposé dans le menu

  • Les propriétaires et admins peuvent réordonner les onglets directement dans la barre de navigation
  • Feedback visuel en temps réel pendant le glissement
  • Sauvegarde automatique de l'ordre à la fin du drag
  • Ordre persisté en base de données par projet

👁️ Pages visibles

  • Le propriétaire active/désactive les modules du projet
  • La page Budget n'apparaît que pour les projets Client
  • Les membres Clients voient uniquement les pages que le propriétaire leur autorise
🛠️
